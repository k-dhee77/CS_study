# java란?
java는 1996년 1월에 배포된 객체지향 프로그램밍(Object Oriented Programming, OOP) 언어이다. 

## 자바의 특징
- 운영체제 독립
java이전 다른 언어들과 다르게 JVM(JavaVirtualMachine)이 설치된 모든 OS에서 운영체제에 종속되지 않고 독립적으로 실행이 가능하게 만들어졌다.

- 객체지향 언어(Object Oriented Programming, OOP)
자바는 객체지향 프로그래밍 개념을 사용하는 언어이다.
모든 기능은 객체로 만들어 사용하며, 객체란 프로그램을 여러 부품으로 나누는 개념이다. 이는 유지보수와 확장성이 뛰어남을 의미한다.

- 함수형 프로그래밍 지원
JAVA 8 부터 함수형 프로그래밍을 지원한여 람다식과 스트림을 사용할 수 있다. 따라서 코드를 간결하게 적을 수 있으며, 컬렉션의 요소를 필터링, 매핑, 집계 처리가 쉽다.

- 자동 메모리 관리
자바는 C++ 언어를 개선하는 것이 목표였다. 따라서 자바는 Gabage Collector를 통해 프로그램 실행 중 필요한 동적 메모리를 자동으로 관리한다.
